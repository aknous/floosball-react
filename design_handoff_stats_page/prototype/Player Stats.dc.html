Filters up top, columns get the room

Leaders band and MVP are gone — pure stats. 1b’s controls (pill groups, status chips with counts) move into a filter bar across the top, so the 232px rail comes back as table width. That buys five more columns at the same density: catch rate, air yards, YAC, separation, drops and long all sit on screen with the box-score line, no expand and no horizontal scroll. The page is now the whole stats surface: a PLAYERS / TEAMS switch beside the title, and team stats get the identical shell — 2b offense, 2c defense, the SIDE pill swapping the column set the same way the position filter does for players. One row height, one header, three column widths, one number style, everywhere.

TURN 1

One table, every stat

The mess today is that every position renders a differently-sized table. Both directions below fix that the same way: one shell — one row height, one header, three column widths (44 count, 52 rate, 58 volume), one number style — and the position filter swaps which columns sit in it, never how they look. Defense is a peer of offense: the filter runs ALL QB RB WR TE K, then a rule, then S LB CB DE, and picking one swaps to the defensive column set. Season and career are two controls, not two pages. A leaders band sits above the table and follows the position filter; MVP rank rides in it. Rows tick to select and the toolbar Compare button opens a full-screen comparison. Both are shown at Season 16, position WR, sorted by receiving yards, with three players selected — the difference is 1a keeps a readable row and hides the advanced line behind an expand, while 1b puts a filter rail on the left and shows every column at once.

1a Toolbar Everything in one bar. Readable rows, advanced line behind an expand.
